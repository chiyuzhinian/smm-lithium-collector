# 门户视觉规范 V3 — 深色行情工作台（2026-09-06）

> 本轮前端视觉专项重构的统一设计规范。业务逻辑/数据计算/权限保持不变。
> 方法论：UI/UX Pro Max 三层令牌架构（primitive → semantic → component）+ dataviz 六项校验。

## 1. 设计原则

- **专业行情终端**：墨蓝石墨底 + 有层次深色面板 + 清晰数字 + 克制蓝色强调；适合长时间查价与研究。
- **层次**：页面底层 < 内容面板 < 交互表面（悬停/展开/浮层），逐级提亮。
- **克制**：无纯黑底、无纯白字、无霓虹/发光边框、无大面积渐变、无毛玻璃、无大阴影、无装饰性 KPI。
- **信息层级**：数字阅读效率优先 —— 等宽数字、右对齐、日均价加重、细分隔线。
- **无编造**：不添加无业务意义的卡片，不伪造数据填充版面。

## 2. 颜色令牌（primitive）

| 令牌 | 值 | 用途 |
|------|-----|------|
| `--c-bg` | `#0D1422` | 页面背景 |
| `--c-nav` | `#0B1220` | 顶部导航 |
| `--c-panel` | `#151F30` | 表格/图表/内容面板 |
| `--c-raised` | `#1B283D` | 悬停/展开/浮层表面 |
| `--c-line` | `#2A3A50` | 细分隔线 |
| `--c-ink` | `#E6EDF7` | 主要文字 |
| `--c-ink-2` | `#A5B3C7` | 次要文字 |
| `--c-ink-3` | `#8B9BB4` | 三级文字/坐标轴标签（≥4.5:1） |
| `--c-accent` | `#7DA7FF` | 交互强调/主曲线 |
| `--c-up` | `#FB7185` | 上涨（红） |
| `--c-down` | `#34D399` | 下跌（绿） |
| `--c-warn` | `#E8B34B` | 警告 |
| `--c-danger` | `#F87171` | 危险/错误 |

对比度（相对 `--c-panel`）：ink ≈ 14.6:1、ink-2 ≈ 7.0:1、ink-3 ≈ 4.6:1、accent ≈ 6.6:1 —— 全部满足 WCAG AA（正文 4.5:1 / UI 3:1）。

透明度一律用 `rgb()`/`rgba()` 派生（技能要求 HSL 思路），不引入新裸色：
- 涨跌软底 `rgba(251,113,133,.14)` / `rgba(52,211,153,.14)`
- 强调软底 `rgba(125,167,255,.15)`（选中/激活/焦点环外圈）

## 3. 语义与组件令牌

```css
:root {
  color-scheme: dark;                     /* 原生日期/下拉控件随主题变暗 */
  /* 尺寸 */
  --topbar-h: 56px;                        /* 顶栏 */
  --ctl-h: 36px;                           /* 筛选控件统一高 */
  --thead-h: 40px;                         /* 表头 */
  --row-min-h: 52px;                       /* 数据行最小高 */
  --radius: 8px;  --radius-sm: 6px;
  --content-max: 1400px;
  /* 字体 */
  --sans: 系统中文栈（与现状一致，不引入网络字体）;
  --mono: "SF Mono", ui-monospace, "JetBrains Mono", Menlo, Consolas, monospace;
  /* 数字：一律 tabular-nums + tnum，价格列右对齐 */
}
```

## 4. 表格规则（每日报价 / 走势明细 / 全量数据 / 月报预览）

- 表头 40px，12px/600，`--c-ink-3`，底色 `--c-panel`，底部 1px `--c-line`；**滚动粘性** `top: var(--topbar-h)`（不压顶栏）。
- 数据行 52–60px：产品名第一层（13.5px/600 `--c-ink`），规格·组织·类别合并为第二层紧凑行（12px `--c-ink-2`，单行省略）；**空规格不再显示占位「—」**，直接显示组织·类别。
- 行分隔 1px `--c-line`；悬停 `--c-raised`；展开行 `--c-raised`。
- 数字列：右对齐 + mono + tabular-nums；日均价 700 加粗；千分位只给整数部分加（**保留源小数精度**，元/Wh 尾零不丢）。
- 涨跌：带正负号，涨红 `--c-up` 跌绿 `--c-down` 持平 `--c-ink-3`；色底徽标 6px 圆角。
- 1440×900 首屏 ≥10 行完整报价（不缩小字号实现）。
- 标签降噪：口径/频次等状态用小号无底文字标签（带点/无胶囊底），组织不再用胶囊。

## 5. 图表规则（价格走势）

- 图表头：标题 + 单位 + 所选时间范围一行；**已选产品图例整合进图表头**（色点+名称+可移除）；单产品时附「最低—最高价」区间带图例样片（**绝不写“置信区间”**）。
- 图表高：桌面 420px（区间 380–460），窄屏 300px；面板底色 `--c-panel`。
- 主曲线：`#7DA7FF`，线宽 2px，圆点 5px；区间带 `rgba(125,167,255,.10)` 填充 + `.30` 边线，低透明度不遮曲线。
- 多序列（≤5）：dataviz 已验证暗色调色板 `#3987e5 #d95926 #199e70 #c98500 #d55181`（对 `#151F30` 全部通过：CVD ΔE≥8.4 / 正常视觉 ≥19.3 / 对比 ≥3:1）；**颜色跟随产品不随排名**（会话内稳定分配）。
- 坐标轴：轴线/刻度 `--c-line`，网格线 `rgba(42,58,80,.55)` 弱化；标签 11px `--c-ink-3`。
- Tooltip：深色（`--c-raised` + `--c-line` 边框），完整 YYYY-MM-DD、产品、最低/最高/日均、涨跌、单位；`confine: true` 不越界。
- 日期轴：`boundaryGap: ['5%','5%']` + `containLabel: true` —— 首尾标签完整；同年区间轴标签 MM-DD，跨年 YYYY-MM-DD（Tooltip 恒 YYYY-MM-DD）。
- 多序列不使用 endLabel 直标（长中文名导致右缘裁切），身份由图表头图例 + Tooltip 承担。
- 数据真实性：缺报断点不补 0、不插值、不平滑；时间轴为真实报价日期。

## 6. 顶栏 / 页头 / 筛选（三栏目统一）

- 顶栏 56px `--c-nav`：品牌区紧凑（中文 15px/700，英文副标 10px 大写弱化）；三主栏目为常规导航，激活态 = 强调软底 + `--c-accent` 文字；质量/运维入口 12.5px `--c-ink-3` 弱化；账号芯片低调。
- 页头一行：标题（18px/700）+ 紧凑状态行（最新报价日期 · 采集更新时间 · 品种数，12.5px，点分隔）+ 主要操作右对齐 —— 标题/状态/操作同一水平区域。
- 筛选栏：字段 = 标签+控件同行（12px 标签），控件 36px，允许换行；搜索框按内容弹性，日期/下拉按需宽度，无大片空白。
- 「数据口径」折叠进可展开面板（`<details>` 风格），保留日期/单位提示。
- 焦点：`outline: 2px accent` + 2px 偏移；禁用 50% 透明度；过渡 150ms。

## 7. 组件与状态

- 弹层（搜索建议/下拉/日历弹层）：`--c-raised` 底 + `--c-line` 边框 + 单层暗阴影，键盘可达（现有 DOM 事件不变）。
- 加载：spinner 16px 强调色 + 12.5px `--c-ink-3`；空态：图标 + 文案。
- Toast：`--c-raised` 底 + 左缘强调色条（error 用 danger）。
- 展开详情：`--c-raised` 底网格，键 11px `--c-ink-3` 值 12.5px `--c-ink-2`。
- 深色滚动条：`--c-line` 轨道透明 + 滑块 `--c-line`。
- 登录/注册/账号页同套深色（auth 卡片 `--c-panel`）。
- Excel 导出：网页深色样式**不写入**导出文件（月报 Excel 保持既有业务模板与打印友好格式）。

## 8. 验收基线

- 视口：1440×900 / 1920×1080 / 1280 / 375 / 浏览器 125% 缩放 —— 无横向溢出。
- 交互：搜索、筛选、日期、行展开、指标切换、产品对比、报表下载全可用。
- 图表：首尾日期完整、Tooltip 不越界、窄屏刻度自动减密不重叠。
- 长产品名/长规格/大价格/小数价格不挤坏布局；深色下无残留白色控件。
- 业务数据与计算与重构前一致（接口未改，只动展示层）。
