# SMM 磷酸铁锂正极材料价格点调整 — 官方公告证据摘要

> 本文件为映射决策依据存档（原文抓取自 SMM 官网，2026-09-06 核实）。
> 抓取页 HTML 存档：`docs/smm_announce_104009835.html`、`docs/smm_announce_103808001.html`。

## 正式公告（2026-07-17 10:37 发布）

- 标题：【SMM公告】关于修改SMM磷酸铁锂正极材料价格点公告
- 链接：https://news.smm.cn/news/104009835
- 关键内容：SMM 已于 2026-03-16 发布《关于修改磷酸铁锂正极材料价格点征询函》，经征询后
  "决定按照征询函中所述方案，正式对磷酸铁锂正极材料相关价格点进行调整。
  **新版价格点将于今日起正式上线**（2026-07-17）。"

## 征询函（2026-03-16 发布，方案 4 月 20 日预告上线）

- 链接：https://news.smm.cn/gonggao/103808001
- 总原则原文："定价从终端应用场景（动力、储能）、循环寿命等技术指标**转向以粉体压实为主**"

| 调整 | 内容 |
|------|------|
| 调整1 | 新增 "压实密度≥2.60g/cm³" 价格点（0.1C放电克容量≥156mAh/g，粉体压实密度≥2.60±0.02，三吨压力机） |
| 调整2 | "磷酸铁锂（动力型压实密度≥2.55g/cm³）" **改名**为 "压实密度≥2.55g/cm³" 并更改定义（删除80%循环保持率3000-4000周描述，密度改为粉体压实密度±0.02三吨压力机） |
| 调整3 | "磷酸铁锂（动力型压实密度≥2.50g/cm³）" **改名**为 "压实密度≥2.50g/cm³" 并更改定义 |
| 调整4 | "磷酸铁锂（动力型压实密度≥2.40g/cm³）" **改名**为 "压实密度≥2.40g/cm³" 并更改定义 |
| 调整5 | "磷酸铁锂（储能型压实密度≥2.50g/cm³）" **并入** "压实密度≥2.50g/cm³" 价格点 |
| 调整6 | "磷酸铁锂（储能型压实密度≥2.40g/cm³）" **并入** "压实密度≥2.40g/cm³" 价格点 |
| 调整7 | "磷酸铁锂（储能型压实密度≥2.30g/cm³）" **改名**为 "压实密度≥2.30g/cm³" 并更改定义（删除80%循环保持率7000-8000次描述） |
