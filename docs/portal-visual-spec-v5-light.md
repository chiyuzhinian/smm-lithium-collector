# 门户视觉规范 V5 — 浅色主题附录（2026-09-09）

> 本文档是 `docs/portal-visual-spec-v3.md`（深色行情工作台）的**浅色主题附录**。
> V3 的组件结构、尺寸、排版规则不变；V5 只替换颜色令牌与图表常量。
> 背景：系统上线多人访问，按业务要求整体改为蓝白配色（参考富宝价格网站风格），
> 主色蓝色、背景白色、辅助浅蓝灰，禁止大面积黑色。

派生透明色同步换主色相（accent → rgba(37,99,235,…)、up → rgba(220,38,38,…)、
down → rgba(22,163,74,…)）；阴影改为浅色 rgba(15,23,42,.06/.12)；滚动条/选区/焦点环同步。

## 2. 组件层规则（V5 追加）

- 按钮 primary = 蓝底白字（#2563EB / #FFFFFF），hover #3B82F6——白字在浅色下对比达标
- 激活导航/分段控件 = `--c-accent-soft` 底 + #1D4ED8 文字
- 徽标/标签：涨红跌绿语义不变（up/down 色相沿用 V3 语义）
- 新增控件：`.pick-input`（多选触发按钮，与 .ctl 同高）、`.chips-row`（筛选栏内 chips 整行）、
  `.chip-unit` / `.chip-empty`（图例 chip 内单位与「暂无历史价格」标注）

## 4. 验收基线

- 1440×900 无大面积深色块（背景浅蓝灰、面板白、顶栏白）
- 主按钮蓝底白字、链接蓝、数字等宽右对齐、涨红跌绿
- 403 页自包含样式与主题一致（白底卡、蓝主色）
- 旧版页面（today/history/topics）style.css 浅色 + app.css 浅色叠加后视觉统一
